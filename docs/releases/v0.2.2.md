## 更新亮点

- **飞鼠控制板点按手势**：惯性 / 激光飞鼠控制板新增「轻点左键 · 双击右键」支持（内置 `165ms` 离合阈值与 `75ms` 点击防抖锚点，零光标飘移且不影响按住挥腕移鼠），可在「指针与飞鼠设置」自由开关并支持一键恢复默认。
- **多样化语音触发模式**：在「全局设置 → 语音触发」新增 **「按住说话」「点击常开」「智能双模（轻点锁定常开 · 长按松开发送）」** 三档模式，常开聆听时配备独立一键取消按钮与全生命周期自动安全收尾。
- **徕卡机械棘轮按键音（默认关闭）**：声学合成器升级为精密相机棘轮/快门曲线，修复国产系统触摸音流静音与扬声器功放冷启动吞音问题，并将发声范围严格收敛至纯操控面板区（常规 UI 导航与设置保持静默）。
- **视觉防切边与分级强提示重构**：补充内部滚动视口出血安全区，根治全机型贴边按键选中框与拖拽放大裁切；重构自适应底部浮动 HUD 胶囊、空按键物理微摇提示与未连接态「立即配对」一键引导胶囊，消除页面跳动。
- **全局无障碍（TalkBack）适配**：全面补齐 Android WebView 无障碍暴露、开关 `role="switch"` 状态播报、滑块倍速读数、无字触控区手势语音说明与 37 项中文图标读屏标签。
